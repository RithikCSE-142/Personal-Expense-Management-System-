# Personal Expense Management System

## Project Overview

The Personal Expense Management System is a web application designed to help users record and manage their daily income and expenses. It provides a simple dashboard to monitor spending, calculate balances, and review monthly financial summaries.

## Objectives

- Record and manage income and expenses.
- Organize transactions by category.
- Calculate total income, expenses, and remaining balance.
- View monthly financial summaries and charts.
- Search and filter transaction records.
- Export transaction data as a CSV file.

## Features

- Dashboard with financial summaries.
- Add, edit, and delete transactions.
- Income and expense categories.
- Transaction history with search and filters.
- Monthly reports and charts.
- CSV export functionality.
- Persistent browser storage.

## Technologies Used

- React
- TypeScript
- Tailwind CSS
- Recharts
- Browser localStorage

## Installation and Execution

1. Install Node.js on your computer.
2. Clone or download this repository.
3. Open the project folder in Visual Studio Code.
4. Install the required dependencies:

   ```bash
   npm install
   ```

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open the local URL displayed in the terminal.

## Data Storage

The application uses browser localStorage to save transaction records. Data is stored locally in the browser and is not automatically synchronized across devices.

## Project Purpose

This project demonstrates frontend development, form validation, transaction management, data persistence, financial calculations, data visualization, and responsive web design.
